# misuka vs. pyroomacoustics: a room-acoustics comparison suite

Companion code for a Bachelor's thesis on extensions to **misuka**, an
acoustic Monte Carlo path tracer built on top of [Mitsuba](https://www.mitsuba-renderer.org/),
and its integration into **CHORAS**, a room-acoustics simulation comparison
platform. This suite compares misuka's pure path-tracing renderer against
[pyroomacoustics](https://github.com/LCAV/pyroomacoustics)' hybrid
image-source-method + ray-tracing simulator across a range of room
geometries, from simple parametric shoeboxes to a real, measured
architectural space.

**Research question:** market-standard room-acoustics software combines
ray tracing with the image source method (ISM) as a hybrid model. misuka is
a pure Monte Carlo path tracer with no ISM. Does a sufficiently high sample
count let pure path tracing match a hybrid ISM+RT simulation, and if not,
in which scenarios (simple vs. complex geometry, diffuse vs. specular
materials, many simultaneous reflections, flutter echoes, a real
architectural mesh)?

## What's in here

| File | Purpose |
|---|---|
| `test_pyroomacoustics_comparison.py` | Scene definitions (shoebox, L-room, flutter corridor, coincident-reflections, real-mesh auditorium) and the core render/compare functions for both simulators, plus the direct-sound time-axis alignment logic (misuka's finite-sphere emitter vs. pyroomacoustics' point source, and pyroomacoustics' own frac-delay-filter lead-in). |
| `pra_comparison_metrics.py` | ISO 3382 acoustic descriptors (T20/T30/EDT/C50/C80/D50/G/TS) via [pyrato](https://pyfar.org/), JND thresholds, error metrics, and `necessary_rays()` (minimum ray count for a given detection confidence, after Richter's Masterarbeit). |
| `pra_comparison_bras_cr4.py` | Geometry/material import for a real benchmark room (BRAS "CR4" auditorium): merges a triangulated mesh into the small number of planar polygons pyroomacoustics needs, builds matching misuka (`acousticbsdf`) and pyroomacoustics (`Wall`) scenes from one shared material table. |
| `pra_comparison_runner.py` | Orchestrates every comparison section (repeated renders, aggregation, alignment) and persists results via `pra_comparison_storage`. Run directly to (re)generate all stored results. |
| `pra_comparison_plots.py` | All figures and tables, built from stored results only (no rendering here). |
| `pra_comparison_storage.py` | Small JSON+`.npz` persistence layer for comparison runs. |
| `pyroomacoustics_comparison.ipynb` | The actual report: loads stored results and calls the plotting functions above, section by section. |
| `plot_scenario_geometries.py`, `export_scenario_geometries_obj.ipynb` | Static 2D/3D geometry overviews and `.obj` export of each room (for external tools, e.g. Blender). |
| `pra_comparison_assets/` | Room geometry inputs: `.obj` exports of the parametric rooms, and (not included, see below) real-mesh assets for the auditorium scenario. |
| `pra_comparison_results/` | Example rendered figures. |

## Requirements

- A misuka build with an acoustic variant (`llvm_ad_acoustic` or
  `cuda_acoustic`) — this is a fork of Mitsuba 3 with an `acoustic_path`
  integrator and `acousticbsdf` material model; not part of this repo.
- Python packages: `numpy`, `scipy`, `matplotlib`, `pandas`, `pyroomacoustics`,
  `pyfar`, `pyrato`.

## Running

```bash
# regenerate all stored comparison results (slow -- renders every scenario)
python pra_comparison_runner.py

# or a faster subset (skips the two slowest sections)
python -c "import pra_comparison_runner as r; r.run_edc_runtime_and_appendix()"
```

Then open `pyroomacoustics_comparison.ipynb` to view the report, which reads
exclusively from `pra_comparison_data/` (generated by the runner, not
committed to this repo -- see below) via `pra_comparison_storage.load_run()`.

## Not included in this repository

- **`pra_comparison_data/`** -- generated comparison results. Several of
  these arrays are hundreds of MB (well past GitHub's per-file limit) and
  are fully reproducible by running `pra_comparison_runner.py`.
- **`pra_comparison_assets/bras_cr4/`, `pra_comparison_assets/bras_cr4_v2/`**
  -- geometry and measured reference data for the real "CR4" auditorium
  scenario, from the BRAS benchmark (Brinkmann, Aspöck et al.,
  *"A benchmark for room acoustical simulation. Concept and database"*,
  Building and Environment, 2021). Not redistributed here; obtain it from
  the original benchmark release and place it under these paths to
  reproduce the auditorium scenarios locally.

## Methodology notes

- All cross-renderer metrics are scale-invariant (reverberation time, clarity/definition ratios, EDC-shape correlation) rather than absolute energy, since misuka (radiometric emitter, solid-angle sampling) and pyroomacoustics (unit point source) use different absolute energy conventions.
- Every ray-tracing-based comparison is repeated (independent seeds) and reports mean ± standard deviation, not a single render.
- Known, systematic offsets between the two simulators' time axes (the source's finite radius, pyroomacoustics' own fractional-delay-filter lead-in) are corrected for before computing time-sensitive parameters -- see `align_hull_to_center`/`shift_later_lossless` in `test_pyroomacoustics_comparison.py`.
